Cómo usar CalcuLab
  1. Pulsa Ver Cámara y acepta el permiso. Muestra la palma de las manos a la cámara.
  2. Mano derecha (rosa): muestra de 1 a 5 dedos para elegir la interacción. La punta del índice mueve el punto x = a.
  3. Mano izquierda (turquesa): ✊ puño y mueve para desplazar · ☝ índice y abre/cierra la pinza con el pulgar para hacer zoom · ✋ abierta para soltar.
  4. Función: escribe cualquier función de x y pulsa Graficar. Usa ^ para potencias, sqrt(), sin(), cos(), tan(), ln(), e^x, abs(). Ejemplo: x^2*sin(x).
  5. Sin cámara: botones o teclas 1–5 para el modo, clic o flechas ← → para mover a, arrastrar para desplazar, rueda para zoom, R para reiniciar, N para un nuevo reto.
